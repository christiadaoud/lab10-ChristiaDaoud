1. OBJECTIVE

The objective of this lab was to implement a Jenkins CI/CD
pipeline for a Python application, automating code quality
checks, unit testing, coverage analysis, security scanning,
and deployment.

2. IMPLEMENTATION

A Python application was created with an automated unit
test using pytest.

The Jenkins pipeline was configured to retrieve the project
from GitHub and execute six stages:

Setup:
Created a Python virtual environment and installed dependencies.

Lint:
Used Flake8 to verify Python code quality.

Test:
Executed automated unit tests using pytest.

Coverage:
Used coverage.py to measure test coverage and generate
an HTML coverage report.

Security Scan:
Used Bandit to scan the Python application for security issues.

Deploy:
Executed a local deployment script that copied the application
to a deployment directory and verified its execution.
